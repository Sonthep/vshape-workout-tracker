# Default 4-Day Program

Equipment: dumbbells + floor + bodyweight only.

## Day 1 — Monday — Back + Side Delts + Biceps
1. One-Arm Dumbbell Lat Row — 3 x 8–12 / side
2. Dumbbell Bent-Over Row — 2 x 8–12
3. Dumbbell Floor Pullover — 2 x 10–15
4. Dumbbell Lateral Raise — 3 x 12–20
5. Dumbbell Curl — 2 x 10–15

## Day 2 — Tuesday — Legs + Chest + Abs
1. Goblet Squat — 3 x 8–12
2. Dumbbell Romanian Deadlift — 3 x 8–12
3. Dumbbell Floor Press — 3 x 8–12
4. Push-Up — 2 x 8–15
5. Reverse Crunch — 2 x 12–20
6. Plank — 2 x 30–60 sec

## Day 3 — Thursday — Lats + Shoulders + Triceps (V-Shape Priority)
1. One-Arm Dumbbell Lat Row — 3 x 10–15 / side
2. Standing Dumbbell Shoulder Press — 3 x 8–12
3. Dumbbell Lateral Raise — 3 x 12–20
4. Bent-Over Rear Delt Fly — 2 x 12–20
5. Dumbbell Floor Pullover — 2 x 10–15
6. Overhead Dumbbell Triceps Extension — 2 x 10–15

## Day 4 — Saturday — Legs + Chest + Back Assistance + Abs
1. Dumbbell Reverse Lunge — 3 x 8–12 / side
2. Dumbbell Romanian Deadlift — 2 x 10–15
3. Dumbbell Floor Press — 3 x 10–15
4. Dumbbell Rear-Delt Row — 2 x 10–15
5. Dumbbell Lateral Raise — 2 x 15–20
6. Plank — 2 x 30–60 sec
7. Dumbbell Crunch — 2 x 10–15

## Progression
Use double progression. Stay within the prescribed rep range. When all work sets reach the top of the range with good form and roughly 1–3 RIR, increase load at the next suitable increment.

## Beginner ramp-up
For the first four weeks, use 2 work sets for smaller isolation exercises and 2–3 work sets for compound exercises. Finish most sets with roughly 2–3 RIR while technique is still being learned. Move to the full listed volume only when recovery and form remain consistent.

## Programming basis
The plan distributes major muscle groups across at least two weekly exposures where practical, uses multiple sets, and gives extra—but not excessive—volume to the lats and lateral/rear delts for the V-shape goal. This follows the current ACSM emphasis on progressive resistance training, individualization, and consistency rather than unnecessary complexity.
