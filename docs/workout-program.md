# Default 4-Day Program

Equipment: dumbbells + floor + bodyweight only.

## Day 1 — Monday — Back + Biceps
1. Dumbbell Bent-Over Row — 3 x 8–12
2. One-Arm Dumbbell Lat Row — 3 x 10–15 / side
3. Dumbbell Floor Pullover — 3 x 10–15
4. Dumbbell Reverse Fly — 2 x 12–20
5. Dumbbell Curl — 2 x 10–15
6. Hammer Curl — 2 x 10–15

## Day 2 — Tuesday — Chest + Shoulders + Triceps + Abs
1. Dumbbell Floor Press — 3 x 8–12
2. Push-Up — 2 x 8–15
3. Standing Dumbbell Shoulder Press — 3 x 8–12
4. Dumbbell Lateral Raise — 3 x 12–20
5. Overhead Dumbbell Triceps Extension — 2 x 10–15
6. Reverse Crunch — 2 x 12–20
7. Plank — 2 x 30–60 sec

## Day 3 — Thursday — Back + Shoulders (V-Shape Priority)
1. One-Arm Dumbbell Lat Row — 3 x 8–12 / side
2. Dumbbell Floor Pullover — 3 x 10–15
3. Dumbbell Rear-Delt Row — 3 x 10–15
4. Dumbbell Lateral Raise — 3 x 12–20
5. Bent-Over Rear Delt Fly — 2 x 12–20
6. Dumbbell Shrug — 2 x 10–15

## Day 4 — Saturday — Legs + Chest + Abs
1. Goblet Squat — 3 x 8–12
2. Dumbbell Romanian Deadlift — 3 x 8–12
3. Dumbbell Reverse Lunge — 3 x 8–12 / side
4. Dumbbell Floor Press — 3 x 8–12
5. Leg Raise — 2 x 10–15
6. Dumbbell Crunch — 2 x 10–15

## Progression
Use double progression. Stay within the prescribed rep range. When all work sets reach the top of the range with good form and roughly 1–3 RIR, increase load at the next suitable increment.

## First two weeks
A beginner or returning trainee may perform ~2 work sets per exercise before moving to full listed volume if recovery is good.
