# UX/UI Principles

## Primary flow
Home -> Start Workout -> Exercise -> Log Set -> Rest -> Next Set/Exercise -> Finish -> Summary

## Home
Show the next workout first. Secondary information: weekly completion and latest progress snapshot. Avoid dashboard clutter.

## Workout mode
- One-handed, thumb-friendly controls.
- Large exercise name and current set number.
- Show previous session values directly next to the input.
- Primary button: Complete Set.
- Auto-start rest timer after completion; user can skip/adjust.
- Keep START -> FINISH form visuals accessible but not dominant.

## Visual language
- Dark navy base, white content surfaces where useful, yellow accent for priority/action.
- Yellow is semantic: priority, active, success/progression callout — not random decoration.
- Minimum practical touch target: ~44px.
- Avoid long paragraphs during active workout mode.

## Accessibility
- Do not rely on color alone.
- Inputs have labels.
- Timer state should be visible as text.
- Support reduced motion.
